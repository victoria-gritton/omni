CloudWatch Omni Homepage - Protozoa Package
=============================================

Upload Instructions:
1. Upload all files in this folder to Protozoa
2. Set "index.html" as the Root File
3. Ensure assets folder is uploaded with the same structure

Files included:
- index.html (ROOT FILE - set this as entry point)
- assets/index-*.js (JavaScript bundle)
- assets/index-*.css (Styles)

The app will automatically load when you open the prototype.

Features:
- Day 0 Homepage with application-centric widgets and attention feed
- Observability Gaps page with tiered gap analysis, batch IaC export (CloudFormation/Terraform/JSON)
- Monitor page with health glance, alarms (Ack/Snooze), SLOs with burn rate, cross-region health
- Persona switcher: Maria (mid-tier greenfield) and James (enterprise fragmented monitoring)
- Agent drawer with contextual investigations, charts, and drill-downs
